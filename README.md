# HowToApp

# Μια σύγχρονη, διαδραστική web εφαρμογή τοπικής εκτέλεσης για την οργάνωση βημάτων και συμβουλών.
# A modern, interactive local web application for organizing steps and tips.

## Τεχνολογίες / Technologies
- **HTML5 / CSS3**: Σύγχρονο, responsive UI/UX / Modern, responsive UI/UX
- **Vanilla JavaScript (ES6+)**: Δυναμική διαχείριση και τοπική αποθήκευση δεδομένων (LocalStorage) / Dynamic management and local data storage (LocalStorage)

## Χαρακτηριστικά / Features
- Κατηγορίες και υποκατηγορίες / Categories and subcategories
- Σειρά εκτέλεσης βημάτων / Step execution order
- Προαιρετική προσθήκη εικόνας ανά βήμα / Optional image support per step
- Τοπική λειτουργία χωρίς server / Local execution without a server
